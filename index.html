Découvrir JavaScript

À quoi ça sert, comment ça tourne, premier script

JS · Fiche Originale

💡 En clair

JavaScript est le langage qui donne vie aux pages web. Le HTML est le squelette, le CSS l'habillage, et JavaScript le cerveau : c'est lui qui réagit aux clics, change le contenu et fait des calculs.

📖 Mots à connaître
consolela zone où le code écrit ses messages. Dans le navigateur : appuie sur F12 puis clique sur l'onglet « Console ».
console.log(...)l'instruction la plus utilisée par les débutants : elle affiche ce que tu mets entre les parenthèses.
//un commentaire : le texte après // est ignoré par la machine. C'est écrit pour l'humain.
JS
console.log("Bonjour JavaScript !");
✏️ Ligne par ligne
// Afficher un messagecommentaire — jamais exécuté
console.log(...)affiche dans la console
"Bonjour JavaScript !"du texte (entre guillemets)
;termine l'instruction, comme un point final
Console
Bonjour JavaScript !
⚠️ Pièges fréquents
  • JS est sensible à la casse : console.log marche, Console.Log provoque une erreur.
  • Oublier les guillemets autour d'un texte (console.log(Bonjour)) → erreur : sans guillemets, JS cherche une variable nommée Bonjour.

JS · Fiche Originale

💡 En clair

Trois mots pour une seule idée : JavaScript est le langage que tu écris, ECMAScript est le cahier des charges officiel (les règles du jeu), et le moteur est le programme qui traduit et exécute ton code.

📖 Mots à connaître
ECMAScriptla norme officielle du langage (ex. « ECMAScript 2024 »). Grâce à elle, le même code fonctionne sur Chrome, Firefox et Edge.
Moteur JSle traducteur + exécutant. Chrome utilise V8, Firefox utilise SpiderMonkey.
Code machinele langage du processeur : uniquement des 0 et des 1. Ton code y est transformé avant d'être exécuté.
✏️ Ligne par ligne
1. Tu cris du codefichier .js, lisible par un humain
2. Le moteur le litV8, SpiderMonkey...
3. Il devient code machine0101 1100...
4. Résultat affichédans le navigateur ou sur un serveur
ℹ️ À savoir

Retiens l'image : le langage est une langue, la norme est le dictionnaire, le moteur est le traducteur.

JS · Fiche Originale

💡 En clair

Même langage, deux terrains de jeu : dans le navigateur (rendre les pages interactives) et sur un serveur avec Node.js (logique, fichiers, base de données).

📖 Mots à connaître
DOMla carte de ta page HTML que JS peut lire et modifier : changer un texte, cacher un bouton, ajouter une ligne...
Node.jsun programme qui exécute du JavaScript hors du navigateur, sur un ordinateur ou un serveur.
APIun service qu'un programme peut interroger (ex. récupérer la météo). fetch est l'outil JS pour appeler une API.
Frontend / Backendce que voit l'utilisateur (interface) / les coulisses (calculs, base de données).
🎯 Bon réflexe

Sécurité : le navigateur limite l'accès à ton ordinateur (pas de fichiers, pas de base de données). Node.js, lui, a un accès complet — c'est pour ça qu'il sert côté serveur.

ℹ️ À savoir

« SPA » (Single Page Application) = une page web qui se met à jour sans se recharger (Gmail, YouTube...).

Variables

let, const, var : stocker et nommer les valeurs

JS · Fiche Originale

💡 En clair

Une variable est une boîte étiquetée : le nom est l'étiquette, la valeur est le contenu. Le symbole = ne veut pas dire « égal » mais « reçoit » : on met la valeur de droite dans la boîte de gauche.

JS
let nom = "Baba";
let age = 20;
let etudiant = true;
✏️ Ligne par ligne
letcrée la boîte
noml'étiquette (le nom de la variable)
=met la valeur dedans
"Baba"la valeur — du texte, donc entre guillemets
20un nombre : jamais de guillemets
trueun booléen (vrai) : jamais de guillemets
Console
nom → "Baba"
age → 20
etudiant → true
🔍 Ce que fait le code

Pour voir ce résultat toi-même, ajoute console.log(nom) : la console affiche la valeur actuelle de la boîte.

⚠️ Pièges fréquents
  • Le texte a besoin de guillemets, pas les nombres ni true/false.
  • La valeur peut changer plus tard « selon le mot-clé » : c'est le sujet des fiches let / const / var.

JS · Fiche Originale

💡 En clair

let déclare une variable dont la valeur peut être remplacée plus tard. C'est le choix par défaut quand la valeur doit évoluer (un score, un compteur...).

JS
let compteur = 10;
compteur = 25;
console.log(compteur);
✏️ Ligne par ligne
let compteur = 10;DÉCLARATION : on crée la boîte avec 10 dedans
compteur = 25;RÉAFFECTATION : on remplace le contenu (sans let !)
console.log(compteur);affiche la valeur ACTUELLE
Console
25
⚠️ Pièges fréquents
  • Ne remets pas let pour changer une valeur : let compteur = 25; recréerait une variable. Une seule déclaration, ensuite juste compteur = ....
  • « À privilégier dans la majorité des cas » = dès que la valeur va changer. Sinon, pense const (fiche suivante).

JS · Fiche Originale

💡 En clair

const crée une constante : la valeur est posée une fois pour toutes. Toute tentative de remplacement déclenche une erreur.

JS
const PI = 3.14;
const nom = "Baba";
console.log(PI);
console.log(nom);
Console
3.14
Baba
JS
const nom = "Baba";
nom = "Niang";
Erreur
TypeError: Assignment to constant variable.
at exemple.js:2
🔍 Ce que fait le code

Le message d'erreur exact est TypeError: Assignment to constant variable : JS refuse de réassigner une constante. La ligne fautive est indiquée à la fin du message.

📖 Mots à connaître
réassignerremplacer la valeur par une autre avec =. Seule la réassignation est bloquée par const.
MAJUSCULEShabitude courante : les constantes « connues » s'écrivent en majuscules (PI, TAUX_TVA) pour les repérer d'un coup d'œil.
⚠️ Pièges fréquents
  • Subtilité importante : const empêche de remplacer la valeur, mais ne fige pas le contenu d'un tableau ou d'un objet (tu le verras avec les objets).
  • Oublier d'initialiser (const x;) est une erreur : une constante doit recevoir sa valeur dès sa création.

JS · Fiche Originale

💡 En clair

var est la façon historique (avant 2015) de déclarer une variable. Ça fonctionne encore, mais le JavaScript moderne utilise let et const.

JS
var nom = "Baba";
var age = 20;
console.log(nom);
console.log(age);
🔍 Ce que fait le code

Pourquoi éviter ? var a des règles de portée anciennes et surprenantes qui provoquent des bugs difficiles à trouver. let et const ont des règles plus saines — tu les croiseras dans tout code récent.

🎯 Bon réflexe

Lis var dans du vieux code → comprends-le comme let. Mais dans TON code, écris const ou let.

JS · Fiche Originale

💡 En clair

Les trois créent des variables. La différence tient en une question : « cette valeur va-t-elle changer ? »

JS
let age = 10;
age = 20;
console.log(age);
Console
20
JS
const PI = 3.14;
// PI = 3.5;  // Erreur !
console.log(PI);
Console
3.14
JS
var score = 10;
score = 20;
console.log(score);
Console
20
✏️ Ligne par ligne
let → valeur modifiable
const → valeur non modifiable (erreur si tu réassignes)
var → ancienne façon : à éviter dans un nouveau code
🎯 Bon réflexe

Réflexe pro : écris const partout par défaut. Si tu te retrouves bloqué (la valeur DOIT changer), remplace par let. Ton code devient plus sûr.

JS · Fiche Originale

💡 En clair

Un nom valide doit commencer par une lettre, _ ou $, ne contenir que lettres/chiffres/_/$, sans espace, et ne pas être un mot réservé.

📖 Mots à connaître
mot réservéun mot déjà pris par le langage : let, if, for... Interdit comme nom de variable.
camelCasepremier mot en minuscule, chaque mot suivant commence par une majuscule : nomEtudiant, prixTotal.
casseJS distingue majuscules et minuscules : age et Age sont DEUX variables différentes.
✏️ Ligne par ligne
let nom = ...✗ interdit : commence par un chiffre
let mon nom = ...✗ interdit : espace dans le nom
let prix-total = ...✗ interdit : le « - » est une soustraction pour JS

let let = 5;✗ interdit : let est un mot réservé

Nom explicite = nom qui se lit comme une phrase : nombreCours plutôt que nb. Dans 6 mois, tu remercieras ton « toi » du présent.

Types de données

string, number, boolean et les autres

JS · Fiche Originale

💡 En clair

Un type est la nature d'une valeur : texte, nombre, vrai/faux... JavaScript possède 7 types primitifs — des valeurs simples, prêtes à l'emploi.

📖 Mots à connaître
primitifune valeur simple et de base (un nombre, un texte...), par opposition aux objets qui sont des ensembles de valeurs.
immuableon ne modifie jamais la valeur d'origine : on en crée une nouvelle. Ex. mettre un texte en majuscules crée un NOUVEAU texte.
déclarer / initialisercréer la variable (let x) / lui donner sa première valeur (= 42).
✏️ Ligne par ligne
let n = 42;number — entier ou décimal
let nom = "Baba";string — du texte, entre guillemets
let actif = true;boolean — vrai ou faux
let x;undefined — déclarée mais jamais remplie
let user = null;null — vide VOLONTAIREMENT
let id = Symbol("id");symbol — identifiant unique
let grand = 9007n;bigint — entier géant (n à la fin)
🎯 Bon réflexe

Les guillemets simples 'Bonjour' et doubles "Bonjour" sont équivalents en JS. Choisis-en un et garde-le.

JS · Fiche Originale

💡 En clair

Ce sont les trois types que tu utiliseras 95 % du temps : texte, nombre, et vrai/faux.

📖 Mots à connaître
stringdu texte, TOUJOURS entouré : ' ', " " ou backticks ``.
numberun nombre, SANS guillemets. Entier (20) ou décimal (99.5) — avec un point, jamais de virgule.
booleantrue ou false, sans guillemets. La réponse à une question oui/non.
JS
let nom = "Baba";
let message = 'Salut';
let titre = `Étudiant`;
Console

99.5
-10
⚠️ Pièges fréquents
  • Décimaux avec un point : 3.14 ✅ — 3,14 ❌ (la virgule a une autre signification en JS).
  • "20" avec guillemets est un TEXTE, pas un nombre : tu ne peux pas additionner proprement dessus (fiches 20 et 57 pour comprendre).

JS · Fiche Originale

💡 En clair

Deux façons de dire « pas de valeur » : undefined = pas encore remplie (JS le fait tout seul), null = vidée exprès (c'est TOI qui le décides).

JS
let x;
console.log(x);
// undefined
Console
undefined
JS
let user = null;
console.log(user);
// null
Console
null
✏️ Ligne par ligne
let x;la boîte existe mais JS y met undefined automatiquement
let user = null;TU décides que la boîte est vide (ex. « pas encore connecté »)
🎯 Bon réflexe

Image à retenir : undefined = boîte jamais remplie. null = boîte qu'on a vidée exprès.

⚠️ Pièges fréquents
  • undefined et null ne sont PAS égales strictement : undefined === null vaut false (fiche 20 pour ===).
  • Une fonction qui ne renvoie rien renvoie... undefined.

JS · Fiche Originale

💡 En clair

Deux types rares : bigint pour des entiers gigantesques (on colle un n à la fin), symbol pour créer un identifiant garanti unique.

📖 Mots à connaître
Number.MAX_SAFE_INTEGERle plus grand entier « sûr » : 9 007 199 254 740 991. Au-delà, les calculs perdent en précision → passe en bigint.
immuableun symbol ne peut pas être modifié une fois créé.
clé d'objetl'étiquette d'une case dans un objet. Symbol sert à créer des étiquettes qui ne risquent pas d'entrer en collision.
JS
let id1 = Symbol("id");
let id2 = Symbol("id");
console.log(id1 === id2);
// false
Console
false
🔍 Ce que fait le code

Même étiquette "id", mais chaque Symbol() crée une valeur unique : les deux symbols ne sont jamais égaux. C'est justement leur utilité.

ℹ️ À savoir

Tu n'en verras pas tous les jours. Retiens simplement : n à la fin = bigint, Symbol() = unique à chaque appel.

JS · Fiche Originale

💡 En clair

typeof répond à la question « quel est le type de cette valeur ? » — et renvoie la réponse sous forme de texte (avec des guillemets).

JS
console.log(typeof 42);        // "number"
console.log(typeof "Bonjour"); // "string"
console.log(typeof true);      // "boolean"
console.log(typeof undefined); // "undefined"
console.log(typeof null);      // "object" (!)
console.log(typeof []);        // "object"
console.log(typeof function() {}); // "function"
Console
"number"
"string"
"boolean"
"undefined"
"object"
"object"
"function"
🔍 Ce que fait le code

Utilisation réelle : tester une valeur avant de s'en servir — if (typeof age === "number") { ... }. Ça évite de faire un calcul sur du texte.

⚠️ Pièges fréquents
  • typeof null → "object" est un bug historique jamais corrigé (pour ne pas casser les anciens sites). null n'est PAS un objet.
  • typeof [] → "object" aussi : pour savoir si une valeur est un tableau, utilise Array.isArray([]) → true.
  • typeof renvoie du TEXTE : compare avec des guillemets — typeof 42 === "number", pas === number.

JS · Fiche Originale

💡 En clair

Les primitifs sont des valeurs simples : on les copie comme une photo. Les objets sont des valeurs complexes : on les partage comme un lien.

JS
let a = 10;
let b = a;      // b reçoit une COPIE de 10
b = 20;
console.log(a); // 10 (a n'a pas changé)
Console
10
JS
let obj1 = { nom: "Baba" };
let obj2 = obj1;        // obj2 pointe vers le MÊME objet
obj2.nom = "Niang";
console.log(obj1.nom);  // "Niang" (modifié !)
Console
"Niang"
🔍 Ce que fait le code

La ligne { nom: "Baba" } crée un objet : une collection avec une case nom. Quand tu copies obj2 = obj1, tu copies l'ADRESSE de l'objet, pas son contenu : les deux variables regardent le même objet.

📖 Mots à connaître
mutable / immuablemodifiable / non modifiable. Les primitifs sont immuables, les objets mutables.
référencel'adresse où l'objet vit en mémoire.
🎯 Bon réflexe

Pour copier VRAIMENT un objet : const copie = { ...original }. Tu verras ça en détail avec les objets.

JS

  • Piège classique : modifier obj2 change aussi obj1 — ce n'est pas un bug JS, c'est le même objet.

Opérateurs

Calculer, comparer, combiner

JS · Fiche Originale

💡 En clair

Les six opérateurs du calcul : + - * / % (reste) et ** (puissance).

📖 Mots à connaître
% modulole RESTE de la division. 10 % 3 : 10 = 3×3 + 1 → 1. Sert surtout à tester si un nombre est pair : n % 2 === 0.
** puissance2 ** 3 = 2 × 2 × 2 = 8.
JS
let a = 10;
let b = 3;
console.log(a + b);  // 13
console.log(a - b);  // 7
console.log(a * b);  // 30
console.log(a / b);  // 3.3333333333333335
console.log(a % b);  // 1
console.log(a ** b); // 1000
Console
13
7
30
3.3333333333333335
1
1000
⚠️ Pièges fréquents
  • La fiche écrit 3.333... : en vrai la console affiche 3.3333333333333335 — les décimaux sont arrondis par l'ordinateur (fiche 62-V).
  • / donne toujours un nombre décimal possible : 10 / 2 → 5, même si c'est un entier.
  • Piège du + : sur du texte, il COLLE les chaînes. "5" + 5 → "55" !

JS · Fiche Originale

💡 En clair

x++ augmente de 1, x-- diminue de 1. C'est le raccourci de x = x + 1 — l'opération la plus courante du monde des boucles.

✏️ Ligne par ligne
x++équivaut à x = x + 1
x--équivaut à x = x - 1
++x (préfixe)augmente D'ABORD, puis renvoie la nouvelle valeur
x++ (postfixe)renvoie D'ABORD l'ancienne valeur, puis augmente
JS
let y = 5;
console.log(y++); // 5 (renvoie avant d'augmenter)
console.log(y);   // 6
Console

6
JS
let x = 5;
console.log(++x); // 6 (augmente avant de renvoyer)
Console
6
⚠️ Pièges fréquents
  • console.log(y++) affiche l'ANCIENNE valeur — piège classique en lecture de code.
  • En dehors des boucles, préfère l'écriture claire : x = x + 1 ou x += 1.

JS · Fiche Originale

💡 En clair

Les opérateurs composés modifient la variable ET affectent en un seul geste : x += 5 est le raccourci de x = x + 5.

JS

🔍 Ce que fait le code

La fiche enchaîne les opérations : chaque ligne part du résultat de la précédente (10 → 15 → 12 → 24 → 6 → 0). Suis la valeur de x ligne par ligne.

JS

message += " World";
console.log(message);
Console

⚠️ Pièges fréquents
  • Ce raccourci marche aussi sur les textes : += COLLE la chaîne (on dit « concaténer »).
  • = affecte, === compare — la confusion entre les deux dans un if est un bug très fréquent (fiches 20 et 31).

JS · Fiche Originale

💡 En clair

=== compare valeur ET type (stricte, recommandée). == compare après avoir converti les types (surprenante, à éviter).

JS
5 == "5"   // true  : "5" converti en 5
5 === "5"  // false : number vs string

0 == false   // true
0 === false  // false

null == undefined   // true (cas spécial)
null === undefined  // false
Console
true
false
true
false
true
false
🔍 Ce que fait le code

Avec ==, JS transforme automatiquement un type en un autre avant de comparer (on appelle ça la conversion ou coercition). Avec ===, si les types diffèrent, la réponse est directement false — aucune conversion.

📖 Mots à connaître
conversion (coercition)JS change un type en un autre tout seul : "5" devient 5 pour permettre la comparaison.
⚠️ Pièges fréquents
  • Règle de survie : utilise TOUJOURS ===. Tu sais exactement ce qui est comparé.
  • [] == false est true (le tableau vide devient 0) — personne ne veut ce genre de surprise.
  • NaN === NaN est false, même avec === (fiche 55).

créer, découper, chercher, remplacer

JS · Fiche Originale

💡 En clair

Une chaîne (string) est du texte. Trois paires de guillemets sont valides : ' ', " " et `` (backticks). Le contenu, lui, ne change pas : une chaîne se crée, se lit, se découpe — mais jamais ne se modifie sur place.

  • Le backtick se trouve sur la touche ` (souvent à gauche du 1, avec AltGr selon les claviers) — pas avec la quote simple !
  • Déclarer = créer la variable ; initialiser = lui donner sa première valeur. const nom = "Baba" fait les deux.

🔍 Ce que fait le code

L'ancienne méthode collait les morceaux avec + : "Bonjour " + nom + ", tu es à " + ville. Les backticks font pareil, sans les fragments de guillemets.

⚠️ Pièges fréquents
  • ${...} ne fonctionne QUE dans les backticks : "Bonjour ${nom}" affiche littéralement ${nom}.
